# CodeX Frontend

A Next.js + TypeScript + Tailwind frontend starter based on the supplied CodeX visual direction.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Included pages

- `/` Landing page
- `/login`
- `/dashboard`
- `/courses`
- `/lesson`
- `/projects`
- `/settings`
- custom 404

## Notes

This package is frontend-only. OAuth, Prisma, Neon, WebContainers, server-side grading,
certificate generation and other backend features should be connected separately.
