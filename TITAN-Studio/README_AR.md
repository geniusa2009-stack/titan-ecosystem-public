# محرك TITAN ‏0.6.0-alpha — الشريحة الرأسية المتكاملة

محرّر سطح مكتب أصلي (**TITAN Studio** بتقنية Qt 6 / QML) متصل عبر بروتوكول محلي ذي إصدار بعملية محرك
تمتلك حالة المشروع والمشهد المرجعية. يتضمن نافذة عرض حقيقية على وحدة الرسوميات، وتحرير الخصائص، والتراجع
والإعادة، والحفظ والاستعادة، وواجهة إضافات أصلية، ومُشغّل «باني العالم» حتمي مع المعاينة ثم الاعتماد.

```bash
brew install cmake ninja qtbase qtdeclarative qtshadertools
cmake -S . -B build -G Ninja && cmake --build build -j 4
ctest --test-dir build --output-on-failure
open "build/bin/TITAN Studio.app"
```

## ما يعمل (تم التحقق على Apple M3 / macOS 26.5.1، ونجحت 9 من 9 مجموعات اختبار)
- يشغّل Studio عملية المحرك ويتفاوض على البروتوكول v1، وينشئ المشاريع ويفتحها مع قائمة بالمشاريع الأخيرة.
- مساحة «العالم»: شجرة المشهد، ونافذة عرض Metal (دوران وتحريك وتكبير، وتحديد بالنقر عبر التقاط المحرك،
  وتحريك بـ ⌥ مع السحب)، ومفتش قابل للبحث، وتراجع وإعادة، وحفظ ثم إعادة فتح بالحالة نفسها.
- سمتان فاتحة وداكنة، ولوحة أوامر (⌘K)، وتكبير النص، وتقليل الحركة، والتبديل بين الإنجليزية والعربية مع عكس
  الاتجاه (الترجمة جزئية).
- باني العالم: إضافة `titan.procedural.scatter`، ثم معاينة شفافة، ثم اعتماد كخطوة تراجع واحدة، مع حفظ الوصفة
  وإعادة توليد انتقائية.

## ما لم يكتمل بعد
لم يُبنَ محرك Unreal بعد (الأرشيف المرفق هو **UE 5.8.4** وليس 4.27)، ولم تُترجَم إضافة الجسر الخاصة بـ Unreal،
ولم يُنفَّذ وكيل الهندسة بعد. التفاصيل في `docs/KNOWN_LIMITATIONS.md` و`docs/TEST_REPORT.md`.
